# ตั้งค่า OpenRouteService (หาเส้นทาง + ค้นหาสถานที่)

แอปใช้ OpenRouteService (ORS) ของ HeiGIT สำหรับหาเส้นทาง (directions) และค้นหา/ระบุชื่อสถานที่ (geocode)
แผนที่ฐานมาจาก OpenFreeMap ไม่ต้องใช้กุญแจ

## 1. สมัครและสร้างกุญแจ

1. สมัครที่ https://openrouteservice.org/dev/#/signup (ฟรี ไม่ต้องใช้บัตรเครดิต)
2. Dashboard → **Request a token** → ประเภท **Standard** ตั้งชื่อ เช่น `navigator-android`
3. คัดลอกกุญแจ (ข้อความยาวขึ้นต้นด้วย `5b3ce...` หรือรูปแบบ base64)

## 2. ใส่กุญแจในเครื่องที่ build

เพิ่มบรรทัดนี้ใน `local.properties` ที่โฟลเดอร์บนสุดของโปรเจกต์ (ไฟล์นี้ไม่เข้า git)

```
orsApiKey=กุญแจที่ได้
```

หรือใช้ตัวแปรสภาพแวดล้อม `ORS_API_KEY` ตอน build (เช่นบนเครื่อง CI)
แล้ว build ใหม่ — ไม่มีกุญแจ แอปยังเปิดแผนที่ได้ แต่ค้นหาและหาเส้นทางไม่ได้ (หน้า "ตั้งค่าและเกี่ยวกับแอป" จะแจ้งเตือน)

**ห้ามใส่กุญแจใน `gradle.properties` หรือไฟล์อื่นที่เข้า git** — repo `suchat-kl/navigator` เป็นสาธารณะ

## 3. โควตาแพ็กเกจฟรี (ตรวจตัวเลขล่าสุดที่ Dashboard)

| บริการ | ใช้ในแอปตอน | โควตาต่อวัน (โดยประมาณ) |
|---|---|---|
| Directions V2 | กด "หาเส้นทาง", เปลี่ยนวิธีเดินทาง, หาเส้นทางใหม่เมื่อออกนอกเส้นทาง (ไม่ถี่กว่า 15 วินาที) | 2,000 |
| Geocode Search | กดค้นหา (ไม่ค้นทุกตัวอักษรเพื่อประหยัดโควตา) | 1,000 |
| Geocode Reverse | แตะค้างบนแผนที่ | 1,000 |

- โควตาเป็นของ **กุญแจเดียวรวมผู้ใช้ทุกคน** ถ้าแอปมีผู้ใช้มากขึ้นจะเต็มเร็ว — ผู้ใช้จะเห็นข้อความ "ใช้บริการหาเส้นทางเกินโควตาแล้ว"
- ทางเลือกเมื่อโควตาไม่พอ: ขอโควตาเพิ่มจาก HeiGIT (มีโครงการสำหรับงานไม่แสวงกำไร), ใช้แพ็กเกจเสียเงิน หรือตั้ง ORS/OSRM ของตัวเองบนเซิร์ฟเวอร์ แล้วแก้ `BASE` ใน `OrsClient.kt`

## 4. ข้อควรรู้เรื่องความปลอดภัยของกุญแจ

กุญแจถูกฝังในไฟล์แอป ผู้ที่แกะไฟล์ APK ได้จะเห็นกุญแจ (เป็นเรื่องปกติของแอปที่เรียก API ตรงจากมือถือ)
ความเสียหายสูงสุดคือมีคนแอบใช้โควตา ถ้าเกิดขึ้นให้สร้างกุญแจใหม่ใน Dashboard ลบกุญแจเดิม แล้วออกแอปรุ่นใหม่
ถ้าต้องการกันอย่างจริงจัง ต้องมีเซิร์ฟเวอร์กลาง (proxy) ถือกุญแจแทนแอป — ยังไม่ได้ทำในรุ่น 1.0.0

## 5. เครดิตที่ต้องแสดง

ORS กำหนดให้แสดงที่มา แอปแสดงไว้ที่ เมนู → ตั้งค่าและเกี่ยวกับแอป → แหล่งข้อมูล:
"© openrouteservice.org by HeiGIT" และ "© ผู้ร่วมพัฒนา OpenStreetMap"
เครดิตแผนที่ฐาน (OpenFreeMap / OpenMapTiles / OpenStreetMap) แสดงอัตโนมัติที่ปุ่ม (i) มุมขวาบนของแผนที่
