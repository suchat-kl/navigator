# คำตอบแบบฟอร์ม Data safety (Google Play)

ตอบตามการทำงานจริงของแอปรุ่น 1.0.0 ถ้าเปลี่ยนการเก็บข้อมูล ต้องแก้คำตอบนี้ด้วย
นิยามของ Google: "เก็บ (collect)" = ส่งข้อมูลออกจากเครื่อง; การส่งให้ผู้ให้บริการที่ประมวลผลแทนเรา (เซิร์ฟเวอร์ระบบนำทางของกรมทางหลวง) ไม่นับเป็น "แชร์"
รุ่น 1.0.1 ขึ้นไป: หาเส้นทาง ค้นหา และจุดเตือน ผ่านเซิร์ฟเวอร์กรมทั้งหมด (navBaseUrl + navSearch=true) ไม่ใช้ OpenRouteService

## คำถามหลัก

| คำถาม | คำตอบ | เหตุผล |
|---|---|---|
| แอปเก็บหรือแชร์ข้อมูลผู้ใช้ประเภทที่กำหนดหรือไม่ | **ใช่** | ส่งพิกัดต้นทาง/ปลายทางและคำค้นไปเซิร์ฟเวอร์ระบบนำทางของกรมทางหลวง (sal.doh.go.th); AdMob เก็บรหัสโฆษณา |
| ข้อมูลเข้ารหัสระหว่างส่งหรือไม่ | **ใช่** | เซิร์ฟเวอร์กรม (sal.doh.go.th), OpenFreeMap, AdMob ใช้ HTTPS |
| ผู้ใช้ขอลบข้อมูลได้หรือไม่ | **ใช่** | ปุ่ม "ล้างข้อมูลทั้งหมดในเครื่อง" (ไม่มีบัญชี ไม่มีข้อมูลที่ผู้พัฒนาเก็บ) |
| แอปต้องสร้างบัญชีหรือไม่ | **ไม่** | ไม่มีบัญชีผู้ใช้ จึงไม่ต้องมี URL ลบบัญชี |

## ประเภทข้อมูล

> เซิร์ฟเวอร์กรมทางหลวงประมวลผลพิกัดเพื่อคำนวณเส้นทางแทนแอปทันทีและไม่เก็บลง log (Nginx `access_log off` ที่ /nav/route) จึงตอบว่า "ประมวลผลชั่วคราว" และ "ไม่แชร์"
> ถ้าภายหลังเซิร์ฟเวอร์เริ่มเก็บพิกัดหรือข้อมูลการเดินทาง ต้องแก้คำตอบนี้และนโยบายความเป็นส่วนตัว

| ประเภท (ตาม Play) | เก็บ | แชร์ | ประมวลผลชั่วคราว (ephemeral) | วัตถุประสงค์ | บังคับ/เลือกได้ |
|---|---|---|---|---|---|
| ตำแหน่ง → ตำแหน่งที่แน่นอน (Precise location) | ใช่ | ไม่ | ใช่ (ส่งเพื่อคำนวณเส้นทางทันที แอปไม่เก็บ) | ฟังก์ชันของแอป | เลือกได้ (ไม่ให้สิทธิ์ตำแหน่งก็ดูแผนที่/ค้นหาได้) |
| ตำแหน่ง → ตำแหน่งโดยประมาณ (Approximate location) | ใช่ (AdMob จาก IP) | ใช่ (AdMob) | ไม่ | การโฆษณา, การวิเคราะห์ | บังคับ |
| กิจกรรมในแอป → ประวัติการค้นหาในแอป (In-app search history) | ใช่ (คำค้นส่งเซิร์ฟเวอร์กรม ไม่เก็บลง log) | ไม่ | ใช่ | ฟังก์ชันของแอป | เลือกได้ |
| ข้อมูลระบุอุปกรณ์หรือรหัสอื่น → รหัสอุปกรณ์/โฆษณา | ใช่ | ใช่ (AdMob) | ไม่ | การโฆษณา, การวิเคราะห์ | บังคับ |
| ข้อมูลแอปและประสิทธิภาพ → ข้อมูลวินิจฉัย, กิจกรรมในแอป (การดู/แตะโฆษณา) | ใช่ (AdMob) | ใช่ (AdMob) | ไม่ | การโฆษณา, การวิเคราะห์ | บังคับ |

> ตรวจรายการของ AdMob ให้ตรงรุ่น SDK อีกครั้งจากหน้า "Google Mobile Ads SDK: Data disclosure" ของ Google ก่อนกรอกจริง

## ข้อมูลที่ไม่เก็บ

ข้อมูลส่วนบุคคล (ชื่อ อีเมล), รายชื่อติดต่อ, รูปภาพ/วิดีโอ, ไฟล์เสียง, ข้อความ, ประวัติการท่องเว็บ, ข้อมูลทางการเงิน, ข้อมูลสุขภาพ
สถานที่ที่บันทึกและการตั้งค่าอยู่ในเครื่องอย่างเดียว (ไม่นับเป็นการเก็บ)

## สิทธิ์ตำแหน่ง (Play Console → App content → Sensitive permissions)

- ใช้ `ACCESS_FINE_LOCATION` + `ACCESS_COARSE_LOCATION` เฉพาะตอนแอปอยู่หน้าจอ
- **ไม่มี** `ACCESS_BACKGROUND_LOCATION` จึงไม่ต้องกรอกแบบประกาศตำแหน่งเบื้องหลังและไม่ต้องส่งวิดีโอ
- ถ้าอนาคตเพิ่มนำทางตอนปิดจอ (foreground service) ต้องประกาศ Foreground service type `location` และอัปเดตเอกสารนี้
